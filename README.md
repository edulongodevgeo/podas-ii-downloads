## Começar do zero

### No computador Windows

1. Baixe e execute o instalador. O programa inclui seu ambiente de execução; não é necessário instalar Python, Git ou Flutter.
2. No assistente, escolha onde instalar e uma **pasta vazia para guardar seus dados**, separada da pasta do programa.
3. Abra **Podas II** pelo atalho. Crie sua primeira solicitação ou importe seus próprios arquivos de entrada.

A carteira começa sem atendimentos. Catálogo de serviços, recursos visuais, modelos e exemplos fictícios de importação são recursos do aplicativo; os exemplos **não são importados automaticamente**. Nenhuma carteira de desenvolvimento acompanha o instalador.

Se o computador já possui Podas II, o instalador pode reutilizar a pasta de dados anterior. Para um ensaio separado, escolha outra pasta vazia; isso não apaga nem move os dados antigos. O Windows pode solicitar verificação da origem, pois o instalador não tem assinatura digital. Em computadores corporativos, siga as orientações da TI. A interface utiliza WebView2, com alternativa no navegador quando disponível.

### No Android

1. Baixe o APK correspondente ao seu papel e abra-o no aparelho. Equipe e Fiscal podem coexistir.
2. Conclua a instalação conforme as permissões autorizadas no dispositivo. Se a política corporativa bloquear a instalação, consulte a TI.
3. O aplicativo novo abre sem lotes. Na **Equipe**, use **Abrir lote** para receber o `.podas` gerado pelo desktop. No **Fiscal**, abra o retorno preparado pela Equipe.

Os APKs são assinados com o certificado do aplicativo. Instalar uma atualização sobre uma instalação existente preserva os trabalhos do aparelho. Não limpe os dados nem desinstale enquanto houver trabalhos não exportados. Em aparelho restaurado de backup, confira se o Android recuperou dados anteriores.

| Etapa | Experimente | Confira |

| **3 · Fiscal** | Confira os serviços e as evidências. Prepare o retorno ao escritório ou solicite uma correção à equipe. | Pareceres e correções acompanham o atendimento. |
| **4 · Desktop** | Receba o retorno, confira a prévia e incorpore. Consolide os atendimentos resolvidos e exporte o relatório. | Os resultados correspondem ao que vocês registraram. |

**Encaminhe cada arquivo `.podas` ao próximo participante pelo canal combinado.** Preparar ou baixar não significa enviar. Cada computador/aparelho guarda seus próprios dados; não há sincronização automática entre carteiras. A exportação não realiza baixa automática no SAP.

### Base elétrica e uso offline

A base elétrica BDGD é fornecida e configurada separadamente; ela não acompanha estes downloads. Para testar a análise elétrica completa, combine a disponibilização da base com o responsável pelo ensaio. Os apps recebem o recorte necessário dentro do lote, sem instalar a base estadual inteira.

O preenchimento e os arquivos locais permitem trabalho offline. Mapas online, imagens e consultas externas dependem de internet. A homologação em tablets corporativos ARM64 e no Google Play Gerenciado/Intune permanece pendente.

## Atualizações

Guarde o endereço desta página. Quando uma nova versão de teste for disponibilizada, os links serão atualizados aqui. **O download e a instalação são manuais.** Faça backup, feche o aplicativo e instale a nova versão preservando sua pasta de dados. O objetivo da atualização é manter seus registros; começar vazio é o comportamento de uma instalação nova sem dados anteriores.

Desktop e Android têm versões independentes. Use a combinação indicada na tabela de downloads. As versões anteriores permanecem disponíveis para identificar qual conjunto foi usado em cada teste.

<details>
<summary><strong>Como conferir o arquivo baixado</strong></summary>

Abra o arquivo de checksums desta versão e localize o nome do download. No PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath 'C:\Downloads\arquivo-baixado.exe'
```

Substitua pelo seu arquivo `.exe` ou `.apk`. O resultado deve ser igual ao SHA-256 informado. Se houver diferença, baixe novamente antes de instalar.

</details>
